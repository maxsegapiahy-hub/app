# Contexto do Projeto: Max Seg & Max Saúde (App Apiahy)

## 📌 Objetivo do Aplicativo
Este é um PWA (Progressive Web App) voltado para proteção e saúde na cidade de Apiaí (Apiahy). O app possui uma interface escura (dark mode), temática corporativa premium (bordô, dourado e padrão de fibra de carbono) e foco em ações rápidas como acionamento de SOS, ronda noturna nos endereços de clientes, carteira de membro e painel de controle.

## 🛠️ Tecnologias Utilizadas
- HTML5, CSS3 nativo (com efeitos 3D e animações).
- Tailwind CSS (via CDN) para estilização rápida.
- FontAwesome 6.4.0 para ícones.
